# OOTP Milestone Tracker UI/UX Audit

이 문서는 `codex/apple-style-ux` 브랜치의 `docs/ux/UX_AUDIT.md`를 현재 개발
브랜치에서 추적할 수 있도록 옮긴 감사 기준이다.

## 우선순위별 개선 항목

1. **P0 — 대량 편집 안전성**
   - 저장 전 전용 미리보기에서 대상 선수, 변경 셀, 제외 항목과 이전값/새 값을 함께 표시한다.
   - 취소를 안전한 기본 동작으로 두고, 완료 후 백업 및 복구 방법을 안내한다.
2. **P1 — 선수 검색 피드백**
   - 메모리 내 필터는 즉시 적용하고 `표시 수 / 전체 수`, 선택 유지, 0건 복구 행동을 제공한다.
3. **P1 — 달성 기록 필터 복구**
   - 결과 요약, 활성 필터, 명시적인 필터 초기화와 빈 결과 상태를 한 영역에 제공한다.
   - 유효한 기존 기록 선택을 유지한다.
4. **P2 — 공통 포커스 및 상태 스타일**
   - 버튼, 입력, 목록, 표, 탭, 체크박스에 일관된 키보드 포커스를 제공한다.
   - 비활성/처리 중/경고 상태를 색상만이 아닌 텍스트와 형태로도 구분한다.
5. **P2 — 기록 정보 계층**
   - 기록 범위, 현재값, 목표값, 남은값의 읽기 순서를 대시보드·선수 상세·예측에서 통일한다.
   - 임박 상태를 색상 이외의 텍스트로도 표시한다.
6. **P3 — 탐색 반응형 및 접근성**
   - 고정 폭 의존을 줄이고 한국어/영어 및 125–150% 배율에서도 탐색 텍스트가 유지되게 한다.
   - 장식 아이콘과 별개로 접근 가능한 텍스트 이름을 제공한다.

## 검증 기준

- 대량 편집 계획 수와 미리보기 수가 일치하고 취소 시 파일이 바뀌지 않는다.
- 검색과 필터는 즉시 반응하며 선택 보존, 0건 상태, 초기화가 동작한다.
- Tab/Shift+Tab으로 주요 제어를 탐색할 수 있고 포커스가 눈에 보인다.
- 한국어/영어, 최소 창 크기, 고배율 환경에서 핵심 텍스트가 잘리지 않는다.
- 통산·시즌·연속 기록의 범위와 현재/목표/남은 값이 텍스트만으로 판독된다.
