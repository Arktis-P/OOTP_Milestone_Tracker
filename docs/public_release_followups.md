# Public Release 후속 작업

이 문서는 `improvement/public-release-ux` 작업에서 발견했지만, 기존 화면과 데이터 계약을 크게 바꾸므로 이번 범위에서 제외한 개선을 추적한다.

## P1 — 다음 개선 주기

### 통합 기록 정보 구조

> 진행 상황: 기존 달성 기록 표·CSV에 이벤트 유형과 자동/수동 출처를 추가했다. 별도 타임라인과 상세 판정 근거는 후속 작업으로 유지한다.

- 마일스톤, 수상, 이적, 부상, 연속 기록을 `event_type`으로 구분한다.
- `grade`는 중요도 축으로 유지하고 이벤트 유형과 분리한다.
- 자동/수동 여부와 데이터 출처를 표와 필터에서 명시한다.
- 기존 달성 기록 화면을 우선 확장하며, 별도 타임라인 화면은 사용성 검증 후 결정한다.
- 완료 조건: 날짜·선수·팀·유형·중요도·자동/수동 필터와 검색, 결과 없음 안내, 상세 근거 진입 경로가 제공된다.

### 선수 상세 확장

> 진행 상황: 선수 기록 화면에 최근 이벤트, 진행 중 연속 기록, 캐시된 다음 마일스톤 요약을 추가했다. 시즌별 변화·개인 최고·즐겨찾기와 모든 주요 화면의 직접 진입은 후속 작업이다.

- 기존 선수 기록 화면을 master-detail 구조로 확장한다.
- 기록·예측 화면의 선수명에서 같은 상세 정보로 이동할 수 있게 한다.
- 시즌별 변화, 수상·이적·부상, 진행 중 연속 기록, 다음 마일스톤, 개인 최고 기록을 한 흐름으로 제공한다.
- 즐겨찾기와 관련 선수 탐색은 위 정보 구조가 안정된 후 검토한다.
- 완료 조건: 어느 주요 화면에서도 선수의 현재 상태와 핵심 이력으로 두 번 이내에 이동할 수 있다.

### 연속 기록 센터

> 진행 상황: 대시보드에서 진행 중·최근 종료 기록을 시즌·선수·팀·유형·검색 조건으로 조회하는 읽기 전용 센터를 추가했다. 시즌/통산 최고, 전체 선수·팀 이력, 과거 DB backfill은 후속 작업이다.

- 기존 `player_streak_state`와 종료 이벤트를 사용하는 읽기 전용 화면부터 구현한다.
- 진행 중 기록, 시즌 최고, 통산 최고, 최근 종료, 종료 사유, 선수·팀별 이력을 제공한다.
- 과거 DB backfill, 동률 최고, 팀 연속 기록 정책은 별도 결정 후 적용한다.
- 완료 조건: 진행 중 상태와 종료 이력을 앱 안에서 확인할 수 있고 CSV 내보내기에 의존하지 않는다.

### 설명 가능한 마일스톤 예측

> 진행 상황: 정규시즌 전체 페이스를 기본 근거로 사용하고, 가능한 항목에는 최근 30개 정규시즌 경기 로그를 보조 근거로 표시한다. 현재값·목표값·남은 수치·예상 추가치와 사용할 수 없는 근거의 이유를 함께 표시한다. 투수는 팀 경기 경과를 확인할 수 없으면 과대 추정하지 않고 예측 불가로 처리한다.

- 기본 기준은 시즌 전체 페이스, 보조 기준은 최근 30경기로 검토한다.
- 정규시즌·포스트시즌·스프링 트레이닝 포함 범위를 명시적으로 결정한다.
- 시즌 종료 예상치, 예상 달성 경기/기간, 이번 시즌 달성 가능 여부를 계산 근거와 함께 표시한다.
- 확률처럼 오해할 수 있는 정밀 표현은 사용하지 않는다.
- 완료 조건: 사용자가 현재값, 목표값, 사용한 경기 구간과 계산식을 확인할 수 있다.

## P1 — 데이터 안전성 정책 선결

### 기록 근거와 수정 이력

- 자동 기록에 source file/hash, 판정 기준 버전, 누적 전후값과 관련 경기를 저장하는 방안을 설계한다.
- 자동 기록 정정은 원본+override 방식과 직접 수정 방식의 장단점을 비교한 뒤 결정한다.
- 선수 병합·분리는 미리보기, 백업, 감사 이력과 되돌리기를 전제로 재설계한다.
- 과거 경기 수정 후 career·team-season 마일스톤을 각 경기 시점의 누적값으로 다시 계산하는 chronological replay를 구현한다. 구현 전까지 안전 재가져오기는 정렬상 최신 경기만 허용한다.

### 세이브 식별과 마이그레이션

- 레거시 공유 DB를 처음 연 세이브에 자동 귀속하는 현재 정책을 명시 연결 흐름으로 바꿀지 결정한다.
- 세이브 폴더 이동·이름 변경에도 유지되는 league identity 도입을 검토한다.
- import 중 세이브 전환 차단과 전환 전후 작업 상태 검증을 추가한다.

### 레이팅 값 정책

- 레이팅 계열, Velocity와 Potential 각각의 최소·최대값을 OOTP 원본 단위에 맞춰 확정한다.
- 반올림 방식과 원래 범위를 벗어난 값의 보존·클램프·제외 정책을 결정한다.
- DOB 누락, 알 수 없는 포지션과 중복 선수 ID의 처리 규칙을 확정한다.
- 사용자 프리셋 저장·불러오기·초기화는 안전 미리보기 흐름이 안정된 뒤 추가한다.

## P2 — 공개 배포 마감

- Windows 100%, 125%, 150% 배율과 1366×768 기준으로 한국어·영어 레이아웃을 검증한다.
- 공통 Empty State, 로딩, 오류·재시도 패턴을 나머지 조회 화면에도 적용한다.
- 도움말, About, 버전·업데이트 진입 경로와 창 위치·크기 복원을 검토한다.
- 빌드 산출물과 `version.txt`, README, CHANGELOG, 릴리스 노트의 버전을 단일 릴리스 절차로 검증한다.
- 체크인된 PyInstaller spec의 개인 절대 경로와 번들 파일 목록을 정리한다.
