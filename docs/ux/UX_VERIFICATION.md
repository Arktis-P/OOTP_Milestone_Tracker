# UX Verification

## 자동 검증

- `pytest -q`
- 필터·선택 보존·0건·대량 편집 계획 요약에 대한 집중 테스트
- `QT_QPA_PLATFORM=offscreen`에서 주요 위젯 생성 및 스모크 캡처

## 수동 시나리오

1. 앱 실행 후 대시보드와 달성 기록이 정상 표시되는지 확인한다.
2. 선수 검색 문자를 입력할 때 결과 수가 즉시 바뀌고 유효한 선택이 유지되는지 확인한다.
3. 검색 결과가 0건일 때 원인과 초기화 행동이 보이는지 확인한다.
4. 달성 기록 필터를 연속 변경하고 현재 범위·결과 수·초기화 경로를 확인한다.
5. 달성 기록에서 선수 상세로 이동한 뒤 같은 선수가 선택되는지 확인한다.
6. 통산·시즌·포스트시즌·연속 기록을 색상 없이도 구분할 수 있는지 확인한다.
7. 가져오기 중 진행률과 취소가 보이고 다른 읽기 탐색이 불필요하게 잠기지 않는지 확인한다.
8. 레이팅 일괄 편집에서 대상 수, 변경 전후, 제외/건너뜀을 저장 전에 확인한다.
9. 미리보기 취소 시 출력 파일이 바뀌지 않는지 확인한다.
10. 저장 실패 시 메모리와 출력이 원상태이고 성공 시 백업·복구 안내가 보이는지 확인한다.
11. Tab/Shift+Tab/Enter/Space/Escape만으로 주요 흐름을 수행한다.
12. 한국어/영어와 최소 창 크기에서 텍스트 잘림을 확인한다.

## 시각 검증 기준

- 포커스가 배경·선택 상태와 구분된다.
- 목록 선택과 상세 패널의 관계가 유지된다.
- 상태·완료·경고·오류·빈 결과가 텍스트로도 구분된다.
- 핵심 숫자가 카드 장식과 보조 설명보다 먼저 읽힌다.
- 과도한 반투명, 바운스, 장식적 이동이 없다.
