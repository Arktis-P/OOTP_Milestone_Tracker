# UX Audit

## 범위와 방법

README, GUI 진입점, 테마, 주요 뷰·위젯과 관련 테스트를 코드 기준으로 추적했다. 실제 화면 검증은 구현 후 오프스크린 스크린샷과 수동 시나리오로 보완한다.

## P0/P1 문제

### 1. 대량 편집 변경 내역이 접힌 상세에 숨음

문제: 저장 전 핵심 변경 내역이 `QMessageBox`의 접힌 상세 텍스트에 들어간다.  
영향: P0 · 대량 편집 안전성  
관련 화면: 레이팅 편집 일괄 편집  
현재 동작: 대상/셀 수만 본문에 보이고 이전값·변경값·제외 항목은 상세를 열어야 확인한다.  
권장 동작: 저장 전 전용 미리보기에서 요약과 변경 표를 함께 보여주고 취소를 기본 동작으로 둔다. 저장 완료 후 백업과 복구 방법을 제시한다.  
근거가 되는 프로젝트 UX 스킬 항목: 대량 편집 안전 규칙, 상태 피드백  
수정 범위: `gui/widgets/bulk_rating_dialog.py` 및 전용 프리뷰 위젯/테스트  
예상 위험: 기존 저장 계획과 실제 적용 범위 불일치  
검증 방법: 계획의 선수·셀·제외 수와 화면 요약 일치, 취소 시 파일 미변경, 실패 시 메모리 복원

### 2. 선수 검색 반응과 결과 맥락이 늦고 약함

문제: 이미 메모리에 있는 선수 목록 검색에 250ms 타이머를 사용하며 결과 수와 선택 유지 상태를 표시하지 않는다.  
영향: P1 · 탐색/상태 피드백  
관련 화면: 선수 기록  
현재 동작: 입력 후 타이머 만료 뒤 목록을 재구성하고, 선택이 사라지면 상세가 비워진다.  
권장 동작: 로컬 필터를 즉시 적용하고 `표시 수 / 전체 수`와 빈 결과 복구 행동을 제공한다. 기존 선택이 남아 있으면 유지한다.  
근거가 되는 프로젝트 UX 스킬 항목: 입력 즉시 피드백, 목록–상세 연결  
수정 범위: `gui/views/stats_view.py`와 관련 테스트  
예상 위험: 많은 선수에서 입력 지연  
검증 방법: 입력 직후 필터, 선택 보존, 0건 상태, 키보드 탐색

### 3. 달성 기록의 다중 필터 상태와 복구가 불명확함

문제: 여러 콤보 필터가 있지만 결과 수, 활성 필터 요약, 0건 상태의 재설정 경로가 분산되어 있다.  
영향: P1 · 정보 구조/탐색  
관련 화면: 달성 기록  
현재 동작: 필터 변경 시 표는 갱신되지만 사용자가 왜 0건인지 빠르게 판단하기 어렵다.  
권장 동작: 결과 요약과 명시적 필터 초기화를 같은 도구 영역에 배치하고 빈 결과를 오류와 구분한다. 선택이 유효하면 유지한다.  
근거가 되는 프로젝트 UX 스킬 항목: 단순성, wayfinding, 빈 상태  
수정 범위: `gui/views/milestone_view.py`와 필터 헬퍼 테스트  
예상 위험: 기존 기록 강조·외부 탐색 선택 해제  
검증 방법: 각 필터 조합, 초기화, 기존 record id 재선택, 빈 결과

## P2/P3 문제

### 4. 공통 포커스·상태 스타일이 불완전함

문제: 입력 포커스는 일부 경계색만 있고 버튼, 목록, 테이블, 체크박스의 키보드 포커스가 일관되지 않다.  
영향: P2 · 접근성/컴포넌트 일관성  
관련 화면: 전체 앱  
권장 동작: 전역 포커스 경계, 비활성/처리 중 상태, 상태별 텍스트+아이콘 규칙을 추가한다.  
수정 범위: `gui/theme.py`, 공통 위젯  
검증 방법: Tab/Shift+Tab, 고대비 팔레트 대비, 색상 없이 상태 판독

### 5. 기록 유형 계층이 표 중심으로 압축됨

문제: 통산·시즌·포스트시즌·연속 기록이 서로 다른 화면과 표에 있으나 제목/값/보조 설명 패턴이 일관되지 않다.  
영향: P2 · 정보 계층  
관련 화면: 대시보드, 선수 상세, 예측  
권장 동작: 기록 범위 라벨, 핵심 값, 현재/목표/남은 값의 순서를 통일한다. 색상만으로 임박 상태를 표시하지 않는다.  
수정 범위: 공통 토큰과 해당 뷰의 표시 계층  
검증 방법: 통산·시즌·연속 샘플의 5초 판독 테스트, 텍스트만으로 유형 구분

### 6. 장식적 이모지와 고정 폭이 정보 밀도에 따라 흔들림

문제: 사이드바 라벨에 이모지가 포함되고 폭이 200px로 고정되어 번역/글꼴 환경에서 정렬이 달라질 수 있다.  
영향: P3 · 시각적 완성도/창 크기  
권장 동작: 기존 탐색 구조는 유지하되 아이콘을 보조 정보로 취급하고 접근 가능한 텍스트와 최소 폭 정책을 보장한다.  
수정 범위: `gui/sidebar_nav.py`, 테마  
검증 방법: 한국어/영어, 최소 창 크기, 125–150% 배율

## 이미 양호한 기반

- 가져오기 작업은 진행률·취소·오류를 제공하고 관련 없는 전체 UI를 일괄 잠그지 않는다.
- `ErrorBanner`가 오류·경고·정보·성공과 행동 버튼을 지원한다.
- 선수 기록은 목록–상세 `QSplitter`로 공간적 관계가 명확하다.
- 대량 편집은 적용 계획, 안전 저장, 백업, 예외 시 메모리 복원을 이미 구현했다.
- 마일스톤 편집은 F2/Delete 단축키와 선택 기반 동작을 제공한다.
