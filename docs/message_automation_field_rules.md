# 메시지 자동화 — 기록 필드 규칙

`messages/` 파서로 수상·이적·부상·포스트시즌을 `milestone_records`에 넣을 때,
기존 수동 입력(`manual_entry.py` / `record_manual_*`)과 **같은 필드 의미**를 따른다.

기준 데이터:

- 기존 수동 기록 샘플 (`data/records.db` — 트레이드 7건, 부상 1건)
- `core/milestone/manual_entry.py` — `build_transfer_records`, `build_injury_description`
- `data/milestones.csv` — 수상·팀 포스트시즌 label/key
- `tests/fixtures/messages/` — OOTP 메시지 샘플

---

## 1. 공통 규칙

### 1.1 DB 컬럼 ↔ UI

| DB 컬럼 | UI (한글) | 의미 |
|---------|-----------|------|
| `achieved_date` | 날짜 | 이벤트 발생일 |
| `player_id` / 선수명 | 선수 | 0이면 팀 기록 |
| `team` | 소속팀 | 선수 소속(또는 팀 기록의 주체 팀) |
| `milestone_label` | 마일스톤(내용) | 짧은 이벤트명 |
| `opponent_team` | 상대팀 | 트레이드·시리즈 상대 등 |
| `opponent_player` | 상대선수 | 기본 **비움** (자동화에서는 사용 안 함) |
| `description` | 설명 | 한 줄 요약 (사람/파서가 읽기 좋은 문장) |
| `notes` | 비고 | 선택. 소스 메시지 ID 등 메타 |
| `season` | (필터) | 시즌 연도 |
| `games_at_achievement` | 경기수 | 수상·이적·부상은 **NULL** |
| `is_manual` | 출처 | 자동 import도 현재는 `1`로 넣거나, 추후 `0`+출처 구분 확장 |

### 1.2 선수 식별

1. 메시지 태그 `<Name:player#ID>`의 **player_id를 최우선** 사용
2. ID가 없으면 `PlayerRegistry.ensure_player(이름)`으로 등록/매칭
3. 표시명은 DB `players.short_name` (예: `Y. Alvarez`) — 메시지 full name을 그대로 넣지 않음

### 1.3 팀명

- 태그 `<Team Name:team#N>`의 **영문 팀명**을 그대로 저장 (기존 기록·박스스코어와 동일)
- 약칭만 있으면 팀 레지스트리로 풀네임 변환
- 추적 팀(예: `Seoul Yukies`) 관련 이벤트만 기록하는 것을 **기본 정책**으로 함  
  (리그 전체 수상 목록 중에서도 추적 팀 소속 선수만 행 생성)

### 1.4 날짜·시즌

| 필드 | 규칙 |
|------|------|
| `achieved_date` | 메시지 메타 날짜(또는 `messages.dat` 일자). 본문에만 연도가 있으면 `YYYY-12-31` 등 **시즌 말 기본일** 사용은 수상에 한정 |
| `season` | 본문 연도(「2026」「2027」) > `season_if_in_season(date)` > `settings.current_season` |

### 1.5 설명 vs 내용

- **내용(`milestone_label`)**: 짧고 고정된 유형명 (「MVP」「트레이드로 합류」「부상」)
- **설명(`description`)**: 사람이 읽을 한 줄 디테일 (누가, 무엇을, 기간/리그/포지션)

## 2. 트레이드 (`manual_transfer_trade`)

기존 기록 예:

| 선수 | 내용 | 소속팀 | 상대팀 | 설명 |
|------|------|--------|--------|------|
| A. Barnes | 트레이드로 합류 | Arizona Diamondbacks | Atlanta Braves | A. Barnes, A. Houser, C. Kilian <> A. Judge 트레이드 |
| A. Judge | 트레이드로 이탈 | Atlanta Braves | Arizona Diamondbacks | (동일 설명) |

### 필드 규칙

한 트레이드 → **선수마다 1행**. 설명 문자열은 전원 동일.

| 필드 | 합류 선수 | 이탈 선수 |
|------|-----------|-----------|
| `milestone_key` | `manual_transfer_trade` | 동일 |
| 내용 (`milestone_label`) | `트레이드로 합류` | `트레이드로 이탈` |
| 선수 | 해당 선수 | 해당 선수 |
| 소속팀 (`team`) | **합류팀** (join_team) | **상대팀** (counterpart = 이탈 후/상대 구단 쪽) |
| 상대팀 (`opponent_team`) | 상대팀 (counterpart) | 합류팀 (join_team) |
| 설명 | `{합류쪽 명단} <> {이탈쪽 명단} 트레이드` | 동일 |
| 상대선수 | 비움 | 비움 |
| 비고 | 선택 (`source:message1433` 등) | 동일 |

### 설명 생성

`build_trade_description`과 동일:

```
Pete Fairbanks, $5,350,000 <> Bryce Meccage, Andrew Fischer, Chandler Welch 트레이드
```

- 이름은 short_name (또는 파싱 시점의 표시명)
- 현금은 `$5,350,000` 형식으로 해당 사이드에 포함
- **관점**: 추적 팀 기준  
  - 추적 팀으로 들어오는 선수 = 합류  
  - 추적 팀에서 나가는 선수 = 이탈  
  - 추적 팀이 관여하지 않으면 **기록하지 않음**

### 추출 소스 예

`trade_multi_player_02.txt`: Milwaukee get Fairbanks+$cash / Miami get 3 prospects → 추적 팀이 MIL이면 Fairbanks=합류, 3명=이탈.

## 3. FA 계약 (`manual_transfer_fa_contract`)

| 필드 | 규칙 |
|------|------|
| 내용 | `FA 계약 합류` (타 팀에서 영입) / `FA 계약 잔류` (자팀 재계약·상대팀 없음) |
| 선수 | 계약 선수 1명 → 1행 |
| 소속팀 | 계약한 팀 (join_team) |
| 상대팀 | 잔류면 **비움**. 타팀 영입이면 이전 팀(알 수 있을 때만) |
| 설명 | `{N}년 ${계약 총액} FA 계약 체결` |

설명 예:

```
1년 $4,880,000 FA 계약 체결
4년 $72,000,000 FA 계약 체결
```

- `{N}` = 보장 계약 연수 (본문 `over 1 year` / `over the upcoming 6 years` 등)
- `${계약 총액}` = 총액이 있으면 총액, 연봉만 있으면 `연봉 × 연수`로 총액 추정

추적 팀이 계약 당사자일 때만 기록.

## 5. 부상 (`manual_injury`)

기존 기록 예: 내용=`부상`, 소속팀=`San Francisco Giants`

| 필드 | 규칙 |
|------|------|
| `milestone_key` | `manual_injury` |
| 내용 | `부상` (고정) |
| 선수 | 부상자 |
| 소속팀 | 발표 시점 소속팀 |
| 상대팀 / 상대선수 | **비움** |
| 설명 | `{부상 종류} 부상으로 {부상 기간} 진단` |

### 설명 템플릿

```
{부상 종류} 부상으로 {부상 기간} 진단
```

| `{부상 종류}` | 규칙 |
|---------------|------|
| 부위 + 부상명 모두 있음 | `오른 팔꿈치 염증`, `왼다리 햄스트링`처럼 **부위와 이름**을 함께 |
| 부위 정보 없음 | 부상 이름만 (`발목 염좌`, `햄스트링`) |

기간 정규화 예:

- `up to one week` / `1 week` → `1주`
- `at least 3 weeks` → `3주`
- `13-14 months` / Tommy John → `시즌 아웃` (또는 본문 개월 수)

추출 예 (`injury_game_03.txt`):

- 선수: Yordan Alvarez  
- 소속팀: Houston Astros  
- 부상 종류: sprained ankle → (번역) `발목 염좌`  
- 기간: one week → `1주`  
- 설명: `발목 염좌 부상으로 1주 진단`

추적 팀 선수만 기록.

## 6. 수상 (award / title)

`milestones.csv`의 **label을 내용으로 사용**. `achieved_value=1`, `games_at_achievement=NULL`.

### 6.1 키 선택 (타자/투수 중복 시)

| 수상 | key 선택 |
|------|----------|
| MVP | 타자 → `bat_season_award_mvp` / 투수 → `pit_season_award_mvp` |
| 사이영상 | 항상 `pit_season_award_cy_young` |
| 신인왕 | 타자/투수 본문에 맞게 bat/pit |
| 올스타 | 타자/투수 포지션에 맞게 bat/pit |
| Great Glove (=골드글러브) | Pitcher 칸 → pit, 야수 → bat (`…_award_gold_glove`) |
| Platinum Stick (=실버슬러거) | 항상 `bat_season_award_silver_slugger` |
| 이달의 타자/투수/신인 | `…_award_player_of_month` (bat/pit·유형 구분) |

### 6.2 필드 공통

| 필드 | 규칙 |
|------|------|
| 내용 | CSV label (MVP, 사이영상, 골드글러브, 실버슬러거, 올스타, 이달의 선수상, 신인왕 …) |
| 선수 | 수상자 (목록형 메시지는 **수상자마다 1행**) |
| 소속팀 | 메시지에 나온 소속팀 |
| 상대팀 / 상대선수 | **비움** |
| 시즌 | 본문 연도 필수 |
| 설명 / 비고 | 아래 유형별 |

목록형(Great Glove / Platinum Stick / All-Star roster)은 추적 팀 소속 수상자만 행 생성.
**이주의 선수(Player of the Week 등)는 기록하지 않음.**

### 6.3 이달의 타자 / 투수 / 신인

| 필드 | 규칙 |
|------|------|
| 내용 | CSV label (`이달의 선수상` 등) — UI에서 구분이 필요하면 설명에 유형을 명시 |
| 설명 | `{유형} ({월}) 수상` |

설명 예 (표시 기준):

| 선수 | 설명 | 뉴스 날짜 → 대상 월 |
|------|------|---------------------|
| 김도영 | `이달의 타자 (5월) 수상` | 6월 1일 뉴스 → **5월** 수상 |
| 문동주 | `이달의 투수 (6월) 수상` | 7월 1일 뉴스 → **6월** 수상 |
| 아유나 | `이달의 신인 (7월) 수상` | 8월 1일 뉴스 → **7월** 수상 |

- 대상 월 = 뉴스 날짜의 **직전 달** (본문에 `April`/`June`이 있으면 본문 월 우선)
- Batter of the Month → `이달의 타자`
- Pitcher of the Month → `이달의 투수`
- Rookie of the Month → `이달의 신인`

### 6.4 MVP / 사이영상 / 신인왕

설명은 투표 결과에 따라:

| 조건 | 설명 |
|------|------|
| 만장일치 | `{1위표 수}표 만장일치로 {상이름} 수상` |
| 그 외 | `{1위표 수}표 {포인트} 포인트로 {상이름} 수상` |

예:

```
32표 만장일치로 MVP 수상
32표 만장일치로 사이영상 수상
20표 187 포인트로 사이영상 수상
```

(현재 세이브는 확장 팀 포함으로 1위표 만장일치 기준이 **32표**)

#### 비고 — 추적 팀 선수 투표 순위

본문 투표표에 **추적 팀 선수**가 2위 이하로 올랐으면 `notes`(비고)에 추가:

```
문보경 10표 200포인트로 2위, 문동주 5표 100포인트로 3위
```

- 수상자 본인이 추적 팀이면 설명만으로 충분하고, 비고에는 **다른 추적 팀 선수**의 순위만 적어도 됨
- 추적 팀 선수가 순위에 없으면 비고는 비움

### 6.5 기타 수상 설명

| 유형 | 설명 예 |
|------|---------|
| Great Glove | `{리그} {포지션}` → `American League SS` |
| Platinum Stick | `{리그} {포지션}` → `American League C` |
| 올스타 로스터 | `{리그} 선발` → `MLB 선발` (투표 시작 메시지는 **기록하지 않음**) |

## 7. 팀 포스트시즌

팀 기록: `player_id=0`, 선수 칸에는 **팀명**이 표시됨.

| 메시지 | milestone_key | 내용(label) | 기록 여부 |
|--------|---------------|-------------|-----------|
| 디비전 우승 | `team_season_division_title` | 지구 우승 | ✅ |
| WS 우승 | `team_season_world_series_win` | 월드시리즈 우승 | ✅ |
| 와일드카드 **진출** | — | — | ❌ (CSV는 「와일드카드 **시리즈 승리**」라 불일치) |
| 플레이오프 **진출** | — | — | ❌ (대응 key 없음) |
| WC/DS/LCS **시리즈 승리** 메시지 | 해당 `wildcard_series_win` 등 | CSV label | ✅ (메시지 확보 시) |

### 필드 규칙 (디비전·WS)

| 필드 | 디비전 우승 | WS 우승 |
|------|-------------|---------|
| 선수 | (팀) Seoul Yukies | (팀) Seoul Yukies |
| 소속팀 | 우승 팀 풀네임 | 동일 |
| 상대팀 | **비움** (디비전) | 패자 팀 (`Detroit Tigers`) |
| 설명 | `{리그/지구} {연도}` → `AL West 2026` | `{연도} {스윕/점수}` → `2027 4-0 스윕` |
| 시즌 | 본문 연도 | 본문 연도 |

추적 팀이 우승/진출 주체일 때만 기록.

## 8. 명예의 전당 (`hall_of_fame`)

| 필드 | 규칙 |
|------|------|
| key | `bat_career_hall_of_fame` 또는 `pit_career_hall_of_fame` (포지션) |
| 내용 | `명예의 전당 입성` |
| 선수 | 헌액 선수 |
| 소속팀 | 알 수 있으면 현/최종 소속, 없으면 비움 |
| 상대팀 | 비움 |
| 설명 | `{리그} 헌액` → `KBO League 헌액` |
| 시즌 | 헌액 연도 (career scope이지만 연도 기록용으로 넣음) |

**투표 시작** 메시지(`The Hall of Fame Voting Begins`)는 기록하지 않음. **Inducts / inducted**만 기록.

## 9. 은퇴

현재 CSV에 은퇴 마일스톤 없음 → **1차 자동화 대상에서 제외**.  
(추후 `manual_event` / `manual_retirement` 추가 시: 내용=`은퇴`, 설명=`은퇴 발표`, 소속팀=발표 팀)

## 10. 기록하지 않는 메시지

| 메시지 | 이유 |
|--------|------|
| Trade Deadline 안내 | 실제 트레이드 아님 |
| All-Star / HOF **투표 시작** | 선발·헌액 확정 전 |
| **이주의 선수** (Player of the Week 등) | 월간 수상만 기록 |
| 와일드카드·PO **진출**만 알림 | CSV key와 의미 불일치 |
| 방출 / 웨이버 / 선수 구매 | 인박스 뉴스 없음 (제외 확정) |
| 추적 팀과 무관한 이벤트 | 기본 필터 |

## 11. 요약 매트릭스

| 자동화 | 내용(label) | 선수 | 소속팀 | 상대팀 | 설명 |
|--------|-------------|------|--------|--------|------|
| 트레이드 합류 | 트레이드로 합류 | 해당 선수 | 합류팀 | 상대팀 | `A, B <> C 트레이드` |
| 트레이드 이탈 | 트레이드로 이탈 | 해당 선수 | 상대팀* | 합류팀 | 동일 |
| FA | FA 계약 합류/잔류 | 선수 | 계약팀 | (선택) | `{N}년 ${총액} FA 계약 체결` |
| 연장 | 연장 계약 잔류 | 선수 | 팀 | 비움 | `{N}년 ${총액} 연장 계약 체결` |
| 부상 | 부상 | 선수 | 소속 | 비움 | `{부상 종류} 부상으로 {기간} 진단` |
| 이달의 타자/투수/신인 | CSV label | 수상자 | 소속 | 비움 | `이달의 타자 (5월) 수상` |
| MVP / CY / ROY | CSV label | 수상자 | 소속 | 비움† | `{표}표 만장일치로 …` / `{표}표 {포인트} 포인트로 …` |
| Great Glove | 골드글러브 | 수상자 | 소속 | 비움 | `리그 포지션` |
| Platinum Stick | 실버슬러거 | 수상자 | 소속 | 비움 | `리그 포지션` |
| 지구 우승 | 지구 우승 | (팀) | 우승팀 | 비움 | `지구 연도` |
| WS 우승 | 월드시리즈 우승 | (팀) | 우승팀 | 패자팀 | `연도 스윕/결과` |
| HOF | 명예의 전당 입성 | 선수 | (선택) | 비움 | `리그 헌액` |

\*이탈 선수의 `team`/`opponent_team`은 기존 `build_transfer_records`와 동일하게 맞춤.  
†MVP·사이영·신인왕: 추적 팀 선수가 투표 순위에 있으면 **비고**에 `선수 N표 M포인트로 K위` 기록.
