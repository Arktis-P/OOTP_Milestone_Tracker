# UI/UX 개선 구현 계획

기준 문서: `docs/OOTP_Milestone_Tracker_UI_UX_Audit.md`

## 작업 배분

### GPT-5.5 — 대량 편집 안전성

- 소유 파일: `gui/widgets/bulk_rating_dialog.py`, 대량 편집 관련 테스트
- 저장 전 펼쳐진 변경 미리보기, 취소 기본 동작, 적용 수량 검증을 구현한다.
- 저장 성공 시 백업·복구 위치를 명확히 안내하고 기존 롤백 보장을 회귀 테스트한다.

### Sonnet 5 — 검색 및 필터 피드백

- 소유 파일: `gui/views/stats_view.py`, `gui/views/milestone_view.py`, 관련 UX 테스트
- 선수 검색 즉시 반응, 결과 수, 선택 보존, 0건 복구 행동을 구현한다.
- 달성 기록 필터 요약·초기화·빈 상태와 유효한 기록 재선택을 구현한다.

### GPT-5.6 (통합) — 접근성, 정보 계층, 반응형 탐색

- 소유 파일: `gui/theme.py`, `gui/sidebar_nav.py`, `gui/views/predict_view.py`,
  `gui/widgets/player_detail_summary.py`, 통합 테스트와 문서
- 공통 포커스/비활성 상태, 접근 가능한 탐색 이름, 최소 폭 정책을 구현한다.
- 예측 및 선수 상세의 현재/목표/남은 값 계층과 임박 상태 텍스트를 정리한다.
- 전체 변경을 검토하고 관련 테스트와 전체 테스트를 실행한다.

## 완료 조건

- P0/P1 항목별 자동화 테스트가 통과한다.
- 공통 포커스 및 접근성 스모크 테스트가 통과한다.
- 기존 메시지 자동화와 시즌 검증 기능을 포함한 전체 테스트에 회귀가 없다.
- 구현 결과와 검증 내역을 별도 완료 보고서에 기록한다.
