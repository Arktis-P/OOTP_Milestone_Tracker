> **현재 최상위 지시서:** [`UI_UX_FINALIZATION_ORCHESTRATOR_DIRECTIVE.md`](UI_UX_FINALIZATION_ORCHESTRATOR_DIRECTIVE.md)  
> 선행 지시서: [`UI_UX_ORCHESTRATOR_DIRECTIVE.md`](UI_UX_ORCHESTRATOR_DIRECTIVE.md)  
> 감사 기준: [`OOTP_Milestone_Tracker_UI_UX_Audit.md`](OOTP_Milestone_Tracker_UI_UX_Audit.md)

## 상태

현재 브랜치는 화면 구조와 주요 페이지를 개편한 **1차 구현 상태**다. 기록 출처, 달성 기록 재설계, 신규 페이지와 기본 메시지 검토 기능은 구현됐지만, 실제 작업 상태 연결·재분석·기존 반영 감지·동적 현지화·공통 폼·실기기 검증이 남아 있다.

따라서 `UI/UX 전면 개선 완료`로 판정하지 않는다. 이후 작업과 완료 조건은 `UI_UX_FINALIZATION_ORCHESTRATOR_DIRECTIVE.md`를 따른다.

## 완료된 기반 작업

1. 기록 출처 모델과 DB 필드
2. 달성 기록 6열 기본 표
3. 기본/고급 필터 분리
4. 선택 기록 상세 패널
5. 기록/데이터 관리/설정 내비게이션 재편
6. 기록 가져오기·수동 기록·연속 기록·고급 도구 페이지
7. 뉴스 메시지 미리보기·승인·날짜 지정 기본 UI
8. 수동 입력의 개별 입력 기본 진입
9. 설정과 고급 도구 분리
10. offscreen 캡처와 신규 자동 테스트

## 최종 마감 Phase

### F0 — 기준 고정

- 현재 테스트와 재현 결함 기록
- 고정 검수 시나리오 준비
- `docs/ux/finalization/BASELINE.md` 작성

### F1 — 가져오기 상태와 실제 동작

- 작업별 영구 상태 저장
- 실제 5단계 상태 전이
- 단계별 버튼 라우팅
- 결과별 화면 이동

### F2 — 대시보드 실제 상태 연결

- 초기 기록·박스스코어·뉴스·오류·시즌 판정 상태 계산
- 작업 후 즉시 갱신
- 앱 재실행 후 상태 유지

### F3 — 뉴스 메시지 검토 완성

- 다시 분석 실제 연결
- 기존 반영·원본 변경 감지
- 메시지별 생성·중복·오류 결과 연결
- 상태 필터와 결과 이동

### F4 — 동적 현지화

- 메시지 category 표시명
- 제외·오류 사유 자연어화
- 내부 클래스명·필드명 기본 노출 제거
- 동적 번역 누출 테스트

### F5 — 공통 안내형 폼

- 수동 입력과 자동 추출 수정 폼 재사용
- 선수 자동완성·팀·날짜·시즌·검증 통합
- 원시 dataclass 편집을 기본 경로에서 제거

### F6 — 기존 출처 마이그레이션 보완

- `notes`의 `source:<message-id>` 등을 이용한 `message_auto` 추론
- 불확실 기록의 안전한 처리
- 반복 실행 가능한 마이그레이션 테스트

### F7 — 실제 화면 검증

- 구조적 geometry 검사
- 1650×900 / 100%
- 1366×768 / Windows 125%
- 최소 창 / Windows 125%
- 한국어·영어 수동 검증

### F8 — CI와 최종 보고

- 재현 가능한 전체 테스트
- CI 실행 근거
- `FINAL_VERIFICATION.md`와 최종 캡처
- 완료·부분 완료·미구현을 사실대로 구분한 보고서

## 오케스트레이터 규칙

- 문서나 테스트만 추가하고 완료 처리하지 않는다.
- UI 위젯 존재와 실제 기능 연결을 구분한다.
- 같은 파일을 여러 에이전트가 동시에 수정하지 않는다.
- GPT-5.5와 Sonnet 5에 구현·검수를 가능한 한 균형 있게 분배한다.
- 차단 요인이 없으면 중간 보고를 최소화한다.
- 전체 테스트 통과는 전체 UI/UX 완료의 충분조건이 아니다.
- offscreen PNG 생성은 Windows 125% 시각 검증을 대체하지 않는다.

## 완료 조건

세부 구현 지시, 파일 소유권, 테스트 목록, 수동 검수 시나리오, 완료 금지 조건은 `UI_UX_FINALIZATION_ORCHESTRATOR_DIRECTIVE.md`를 따른다.
