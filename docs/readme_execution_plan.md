# README 작성 실행 계획

## 목표

OOTP Milestone Tracker를 처음 접한 사용자가 README만으로 다음 내용을 이해하고 실행할 수 있도록 합니다.

- 프로그램이 제공하는 기능
- 설치 또는 실행 방법
- OOTP에서 준비해야 할 데이터
- 앱의 최초 설정 방법
- 기록을 가져오고 확인하는 전체 사용 순서
- 각 화면의 역할과 다음 작업
- 반복 사용과 데이터 갱신 방법

README는 기능 목록만 제공하는 소개 문서가 아니라 **설치부터 첫 결과 확인까지 안내하는 사용자용 시작 문서**로 유지합니다.

## 역할 분담

### GPT — 총괄 및 최종 반영

- 독자와 문서 목표 결정
- 조사 범위와 검증 기준 설정
- 기능 설명 우선순위 결정
- 조사 결과 통합과 충돌 해결
- README 최종 편집
- 변경 내용을 `master`에 직접 커밋

### Codex 단계 — 저장소 조사와 검증

- 실제 사이드바와 주요 화면 조사
- 기능별 코드 경로 확인
- 설치·실행·테스트·빌드 명령 검증
- import 파일명과 설정 항목 확인
- 세이브별 DB와 데이터 저장 방식 확인
- 결과를 `docs/readme_codex_audit.md`에 기록

이번 작업에서는 GitHub 저장소 코드와 문서를 직접 조사하여 Codex 단계의 산출물을 작성합니다. 로컬 Windows 실행이 필요한 항목은 별도로 표시합니다.

## 실행 단계

### 1. 현재 상태 확인 — 완료

- 현재 버전과 기본 브랜치 확인
- 기존 README와 상세 문서 확인
- 실제 UI 화면 목록 확인

### 2. 기능 인벤토리 검증 — 완료

검증 대상:

1. 대시보드
2. 달성 기록
3. 선수 기록
4. 기록 달성 예측
5. 기존 기록 가져오기
6. 레이팅 편집
7. 설정
8. 수동 이벤트 입력
9. 한글 이름 매핑
10. 세이브별 DB 관리

검증 결과는 `docs/readme_codex_audit.md`에 기록합니다.

### 3. 전체 사용 흐름 검증 — 완료

```text
설치 또는 실행
→ OOTP 세이브·시즌·추적 팀 설정
→ 기존 타격·투구 기록 가져오기
→ 박스스코어 가져오기
→ 대시보드와 기록 화면 확인
→ 필요 시 수동 이벤트 추가
→ 새 경기마다 반복 import
→ 필요 시 stats refresh
```

### 4. README 정보 구조 반영 — 완료

README 순서:

1. 프로젝트 소개
2. 프로그램으로 할 수 있는 일
3. 주요 화면과 기능
4. 설치 및 실행
5. OOTP 데이터 준비
6. 처음 사용하는 순서
7. 시즌 중 반복 사용
8. 기능별 사용법
9. 데이터 저장과 세이브 분리
10. 자주 발생하는 문제
11. 개발자용 실행
12. 상세 문서

### 5. 스크린샷 계획 — 계획 완료, 촬영 미완료

최소 권장 세트:

1. 대시보드
2. 선수 기록
3. 기록 달성 예측

세부 촬영 기준은 `docs/readme_screenshot_plan.md`를 따릅니다.

### 6. README 작성 및 직접 반영 — 완료

- UI 명칭을 현재 코드와 일치시킴
- 독립 탭이 아닌 기능을 별도 화면처럼 표현하지 않음
- 설치와 OOTP 데이터 준비를 분리함
- 기능마다 실제 진입 화면과 사용 시점을 표시함
- 최초 사용과 반복 사용을 구분함
- `master` 브랜치에 직접 커밋함
