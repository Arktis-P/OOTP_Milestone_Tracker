# UI/UX 전면 개선 구현 보고서

## 기준과 브랜치

- 작업 브랜치: `codex/ui-ux-audit-improvements`
- 최상위 지시: `docs/UI_UX_ORCHESTRATOR_DIRECTIVE.md`

- 기반 기능: `codex/message-automation-validation`
- 실행일: 2026-07-24

기존 Phase 0 개선은 유지하고, 이번 작업에서 지시서의 Phase 1~3 핵심 흐름을
실제 UI와 데이터 모델에 반영했다.

## 완료

### 기록 출처와 데이터 호환

- `milestone_records.source`와 안전한 기존 DB 마이그레이션을 추가했다.
- `boxscore_auto`, `message_auto`, `manual`, `season_final`,
  `migration`, `validation` 출처를 지원한다.
- 박스스코어, 메시지 자동화, 수동 입력, 시즌 판정, 연속 기록 저장 경로가
  명시적인 출처를 기록한다.
- 기존 `is_manual`은 호환 목적으로 유지한다.

### 달성 기록 화면

- 기본 표를 날짜·대상·팀·기록·유형·출처의 6열로 축소했다.
- 시즌·팀·검색·유형은 기본 필터, 대상·범위·등급·출처는 접이식 고급 필터로
  분리했다.
- 선택 기록의 설명, 달성값, 경기/상대, 판정 근거, 원본 ID, 메모와 동작을
  상세 패널에서 확인할 수 있다.
- 필터 갱신 후 유효한 선택은 유지하고, 제외된 선택은 첫 결과로 이동한다.

### 작업 흐름과 가져오기

- 대시보드를 6단계 작업 진행 패널로 재설계했다.
- 최신 경기, 뉴스 메시지, 통산·과거 시즌을 한곳에서 안내하는 기록 가져오기
  화면을 추가했다.
- 원본 확인→분석→검토→저장→결과 확인의 공통 5단계 상태 모델을 적용했다.
- 완료·부분 성공·오류 결과를 페이지에 유지한다.
- 기존 박스스코어 및 초기 기록 가져오기 기능을 새 정보 구조에서 접근할 수 있다.

### 뉴스 메시지 검토

- 저장 전 메시지 후보, 제외, 날짜 필요, 오류, 이미 반영됨을 요약한다.
- 원문과 추출 결과, 관련 선수/팀, 상태와 이유를 확인한다.
- 선택 승인, 전체 승인, 제외, 재분석, 일괄 날짜 지정과 승인된 항목만 저장을
  지원한다.
- 추출 dataclass 필드를 저장 전에 편집하고 날짜·숫자 타입을 검증한다.
- 승인 전에는 저장 콜백이 호출되지 않으며 저장 출처는 `message_auto`다.

### 수동 입력

- `하나씩 입력하기`를 기본 진입 흐름으로 변경했다.
- 마일스톤·수상·팀 이동·부상별 안내 폼을 사용한다.
- 표 기반 입력은 명시적인 여러 건 일괄 입력 보조 모드로 분리했다.
- 일괄 모드에 저장 가능 건수와 오류 피드백을 표시한다.

### 정보 구조와 보조 화면

- 사이드바를 기록 / 데이터 관리 / 설정의 10개 페이지 구조로 재편했다.
- 연속 기록을 독립 메인 페이지로 통합했다.
- 선수 기록 헤더·최근 이벤트·비율값 표시를 정리했다.
- 예측 등급을 번역하고 계산 근거 상세 패널을 추가했다.
- 일반 설정과 고급·위험 도구를 분리했다.
- 전체 DB 초기화는 세이브명 재입력, 삭제 요약과 백업 안내를 요구한다.
- 시즌 격리 재검사는 QThread에서 별도 validation DB만 사용하며 결과와
  보고서 경로를 페이지에 유지한다.

### 반응형·현지화·접근성

- 공통 `ResponsiveFlowLayout`과 `CollapsibleSection`을 추가했다.
- 1366×768 및 최소 1000×680 화면에서 핵심 컨트롤 접근을 검증했다.
- 신규 화면의 한국어 번역과 등급·상태·출처 표시명을 보강했다.
- 실제 설치 폰트를 확인하는 안전한 앱 폰트 선택으로 기존 첫 후보 고정 버그를
  수정했다.

## 부분 완료

- `messages.dat` 날짜 메타데이터 파서는 아직 없다. 정확한 날짜가 필요한 항목은
  유실되지 않고 날짜 누락 대기 상태로 남으며 검토 화면에서 날짜를 지정할 수 있다.
- 가져오기 화면은 기존 박스스코어·초기 기록 엔진을 연결한다. 세 작업 모두가
  하나의 공통 백엔드 상태 머신을 공유하는 수준까지는 통합하지 않았다.
- 대시보드 상태의 마지막 실행 시각은 현재 저장된 import state로 계산한다.
  뉴스 검토와 시즌 판정의 영구 실행 이력은 별도 저장하지 않는다.

## 미구현

- 사용자별 표 열 표시 설정 저장
- 검토 없이 메시지를 자동 반영하는 고급 옵션
- `messages.dat` 바이너리/메타데이터 직접 파싱

위 항목은 초기 공개 버전의 안전한 `검토 후 저장` 정책에는 필수적이지 않아
후속 작업으로 남겼다.

## 사용자 확인 필요

- 실제 Windows 데스크톱에서 125% 배율의 한국어/영어 글꼴 모양과 긴 문자열
  잘림을 최종 확인해야 한다.
- 자동 캡처 환경의 Qt font database가 비어 있어 PNG의 글자는 tofu로 표시됐다.
  따라서 PNG는 배치·크기·컨트롤 접근 증거이며, 번역은 자동 테스트로 검증했다.
- 실제 OOTP 세이브의 `messages` 경로 변형이 현재 탐색 후보 세 경로에 포함되는지
  확인이 필요하다.
