## 전체 판정

이번 구현은 이전의 검색·포커스 중심 보조 개선을 넘어 화면 정보 구조를 실제로 변경했다. 다만 일부 신규 화면은 실제 작업 상태와 완전히 연결되지 않았고, 메시지 검토·현지화·기존 데이터 마이그레이션·Windows DPI 검증에 결함이 남아 있다.

따라서 이 문서는 `UI/UX 전면 개선 완료 보고서`가 아니다. 최종 완료 여부는 후속 지시서의 F0~F8을 수행한 뒤 다시 판정한다.

## 완료된 기반 작업

### 기록 출처와 데이터 호환

- `milestone_records.source` 필드 추가
- `boxscore_auto`, `message_auto`, `manual`, `season_final`, `migration`, `validation` 지원
- 새 박스스코어·메시지·수동·시즌 판정 저장 경로에 출처 지정
- 기존 `is_manual` 호환 유지

### 달성 기록 화면

- 기본 표를 날짜·대상·팀·기록·유형·출처 6열로 축소
- 기본 필터와 접이식 고급 필터 분리
- 선택 기록 상세 패널 추가
- 필터 갱신 후 선택 유지

### 정보 구조

- 사이드바를 기록 / 데이터 관리 / 설정으로 재편
- 기록 가져오기, 수동 기록, 연속 기록, 고급 도구 페이지 추가
- 설정과 위험 도구 분리
- 선수 기록과 예측 화면 일부 정리

### 뉴스 메시지 검토 기본 UI

- 후보·제외·날짜 필요·오류 상태 표시
- 원문과 추출 결과 표시
- 선택 승인·전체 승인·제외·날짜 지정·저장
- 승인 전 저장 방지

### 수동 입력

- `하나씩 입력하기`를 기본 진입으로 변경
- 표 입력은 일괄 입력 보조 모드로 분리

### 검증 기반

- 신규 자동 테스트 추가
- offscreen 화면 캡처 스크립트와 PNG 생성

## 최종 마감이 필요한 항목

### 1. 통합 가져오기 상태

- 표시된 5단계가 실제 상태 머신과 완전히 연결되지 않음
- 카드의 단계별 버튼이 같은 동작으로 라우팅되는 경우가 있음
- 결과 버튼이 서로 다른 문제 화면을 열지 않음

### 2. 대시보드 상태

- 일부 단계가 실제 실행 이력보다 폴더 존재 여부 또는 고정 상태에 의존
- 뉴스 검토·미처리 오류·시즌 판정의 영구 실행 이력 없음

### 3. 메시지 검토

- 앱에서 `reanalyze_callback`이 연결되지 않아 다시 분석이 무동작
- 스캔 시 기존 반영 메시지를 미리 판별하지 못함
- 메시지별 생성 기록 ID와 중복·오류 결과 연결이 불완전

### 4. 현지화

- 메시지 category와 exclusion reason 내부 코드가 노출될 수 있음
- 추출 결과에서 dataclass 클래스명과 원시 필드명이 노출됨
- 정적 `tr()` 검사만으로 동적 내부값 누출을 검증함

### 5. 공통 폼

- 수동 입력과 메시지 자동 추출 수정이 같은 안내형 폼을 재사용하지 않음
- 메시지 수정은 내부 dataclass 필드를 2열 표로 직접 편집함

### 6. 기존 출처 마이그레이션

- 기존 `is_manual=1` 뉴스 자동 기록이 `manual`로 분류될 수 있음
- `notes`의 `source:<message-id>` 신호를 활용한 보완 필요

### 7. 화면 검증

- offscreen 캡처는 PNG 크기·생성 여부만 증명
- 실제 Windows 125%의 글꼴·잘림·겹침 확인 미완료

### 8. CI 근거

- 기준 커밋에 연결된 GitHub Actions 실행 기록 없음
- 기존 `517 passed, 2 skipped`는 로컬 보고이며 독립 CI 근거가 아님

## 현재 검증 결과
